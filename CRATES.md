# Crates

> Generated by `scripts/public-export.sh` from the private working repo's crate manifests.
> Do not hand-edit — regenerate instead.

BAR Observatory is a thin `bar` CLI facade (crate `bar-observatory`) over a 16-crate
`bar-*` engine (reuse-not-recreate, ADR-017) — 16 of the 17 crates publish;
the rest is dev-only tooling. **Crates.io is the primary distribution
channel** — this public repo carries the front door, documentation, and process
walkthrough only, no crate source. Crate source lives and is published from the private
working repo. Crates publish incrementally, dependency-tier-ordered — a link below means
cleared for publish, not necessarily live yet; click through for the real, current status.

| Crate | Role | crates.io |

**Deliberately not ported/published:** `bar-engine` — an internal-only, more
full-featured CLI (`run`/`matrix`/`delta`/`export`/`label`/`method`) that predates
`bar-observatory`'s public facade. It stays in the private working repo: not ported,
not published. Revisit only if the public `bar` CLI ever needs a command only
`bar-engine` has.
