How this report works

Recorded evidence, not generated judgment

BAR Observatory reconstructs an agentic engineering run from captured Claude Code events, agent lifecycles, repository state, Git history, terminal outcomes, provider usage, file versions, workflow transitions, and deterministic micro-observations.

Highlighted agents and process steps are selected by declared rules such as retry count, validation failures, token concentration, file revisits, abandoned branches, and evidence density. The standard report does not use an LLM and does not infer hidden reasoning, code quality, or business value.
