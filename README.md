# BAR Observatory (Base Agentic Reporter)

A local-only, deterministic **flight-recorder for Claude Code agent sessions**: capture what a
session produced, render an auditable report (JSON + HTML + Markdown) — **same database →
byte-identical output**, no LLM or network in the render path, no API key required.

> **Staging folder — not yet a public release.** Published only after human release approval
> (BAR ADR-016). Everything in this folder is hand-maintained static content — README, RUN.md,
> run.sh, `process/`, `schemas/`, `config/`, `examples/`, LICENSE, SECURITY.md, CONTRIBUTING.md,
> CHANGELOG.md — **except `CRATES.md`**, which is generated by `scripts/public-export.sh` from
> the real crate manifests (`bash scripts/public-export.sh --check` catches drift).

**This repo is the front door + documentation only — no crate source.** Crate code lives in the
private working repo and **publishes to crates.io directly**, which is the primary distribution
channel; see [CRATES.md](CRATES.md) for the full crate list and status.

## ▶ Run it (front door)
See **[RUN.md](RUN.md)**, or just:
```bash
./run.sh <path-to-a-claude-code-session.jsonl>   # builds bar, ingests, renders → ./_run/*.report.html
```

## The process
1. [Init](process/00-init.md) — `bar init` (idempotent, never clobbers)
2. [Config](process/01-config.md) — typed TOML, 5-layer resolver, blake3 integrity
3. [Database creation](process/02-database-creation.md) — one local SQLite/run, create-if-not-exists, portable
4. [Data ingestion](process/03-ingestion.md) — **always-done** transcript ingest (no API calls) + optional capture
5. [Optional modules](process/04-optional-modules.md) — coverage oracles, cost, detectors, interpreted layer
6. [Sample report](process/05-sample-report.md) — a real report re-rendered **each phase** under `examples/`

## Quick start
```bash
bar init --dir .
bar ingest .bar/ambient.sqlite <your-session>.jsonl   # always-done ingest, no API key
bar report .bar/ambient.sqlite --out .                  # JSON + HTML + MD, deterministic
bar query .bar/ambient.sqlite tools                     # direct read-only DB access (--list for more)
```
