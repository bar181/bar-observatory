BAR Observatory is a thin `bar` CLI facade (crate `bar-observatory`) over a
15-crate `bar-*` engine (reuse-not-recreate, ADR-017). **Crates.io is the
primary distribution
channel** — this public repo carries the front door, documentation, and process
walkthrough only, no crate source. Crate source lives and is published from the private
working repo. Crates publish incrementally, dependency-tier-ordered — click through any
link below for that crate's real, current crates.io status.

| Crate | Role | crates.io |

**Deliberately not ported/published:** `bar-engine` — an internal-only, more
full-featured CLI (`run`/`matrix`/`delta`/`export`/`label`/`method`) that predates
`bar-observatory`'s public facade. Kept in the private working repo's origin
(`observatory/crates/bar-engine`), not ported, not public. See root `CLAUDE.md`'s
"Active work" section if this decision needs revisiting.
